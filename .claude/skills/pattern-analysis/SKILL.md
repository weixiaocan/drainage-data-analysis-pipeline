# 排污规律分析

对排水监测点的旱天特征曲线进行统计分析并自动分类。

## 工作流程

1. **计算特征值** - 调用 `scripts/classifier.py` 计算 Kz、波峰数量、时段流量等
2. **规则分类** - 执行分类逻辑，确定第1/2/3类
3. **生成描述** - 使用LLM根据分类结果生成业务描述

## 分类规则（概述）

| 条件 | 分类 |
|------|------|
| Kz<1.2 且无周期性规律 | 第3类（平坦） |
| Kz<1.2 且有周期性规律 | 第2类（泵控） |
| Kz>=1.2 且符合生活污水规律 | 第1类 |
| Kz>=1.2 且不符合生活污水规律 | 第2类 |

**第1类核心条件**：夜间最低 + 晚上高峰明显 + 早/午有小高峰
