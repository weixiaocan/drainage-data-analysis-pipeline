# 排污规律分类规则详解

## 核心概念

### Kz（时变化系数）
- Kz = 最大流量 / 平均流量
- Kz 越小表示波动越小
- Kz < 1.2 表示曲线平坦

### 波动范围
- 波动范围 = (最大值 - 最小值) / 平均值
- 周期性规律需要波动范围 > 30%

### 时段定义
| 时段 | 时间范围 | 分钟索引 |
|------|----------|----------|
| 夜间 | 0-7点 | 0-419 |
| 早上 | 7-10点 | 420-599 |
| 中午 | 11-15点 | 660-899 |
| 下午 | 15-17点 | 900-1019 |
| 晚上 | 18-24点 | 1080-1439 |

---

## 判断顺序（必须严格按顺序）

### 第一步：检查 Kz 值

```
如果 Kz < 1.2:
    只能选择第2类或第3类
    跳到第三步
否则:
    继续第二步
```

### 第二步：Kz >= 1.2 时的判断

```
1. 先检查是否有周期性规律
   - 有 → 第2类（泵控）

2. 再检查是否符合第1类条件
   - 符合 → 第1类

3. 都不符合 → 第2类
```

### 第三步：Kz < 1.2 时的判断

```
1. 检查是否有周期性规律
   - 有 → 第2类（泵控）
   - 无 → 第3类（平坦）
```

---

## 周期性规律判断

### 定义条件（必须同时满足）

1. **波峰数量 >= 4**
2. **有显著深夜波峰**
   - 时间：0-5点
   - 波峰值 > 日均流量

### 区分要点

| 特征 | 生活污水规律 | 周期性规律 |
|------|-------------|-----------|
| 波峰时段 | 集中在早/午/晚 | 分散在全天各时段 |
| 深夜流量 | 最低 | 有显著波峰 |
| 波峰间隔 | 不规律 | 间隔相近(2-5小时) |

---

## 第1类条件（生活污水规律）

### 必须同时满足

1. **夜间流量最低**
   - 夜间平均 < 早上平均
   - 夜间平均 < 中午平均
   - 夜间平均 < 晚上平均

2. **晚上有明显高峰**
   - 晚上峰值 > 日均 * 1.15

3. **早上或中午有小高峰**
   - 峰值 > 日均即可，不要求突出

### 注意事项

- 早午高峰不突出但只要有就算符合
- 夜间占比偏高(>15%)时描述中需指出，但仍归为第1类

## 分类说明

### 第1类 - 符合典型生活用水排放规律

**典型特征**：
- 夜间流量低
- 早上逐渐升高，有小高峰
- 中午维持较高
- 晚上明显高峰
- 夜间逐渐降低

**描述示例**：
> 夜间流量最低，早上和晚上高峰明显，符合典型生活用水排放规律

### 第2类 - 不符合典型生活用水排放规律

**子类型**：

| 子类型 | 特征 | 疑似原因 |
|--------|------|----------|
| 泵站调控 | 周期性波峰，锯齿状 | 泵站间歇运行 |
| 工业排水 | 脉冲式，大部分时间为0 | 工业间歇排放 |
| 公建排水 | 昼高夜低，夜间极低 | 学校/医院/办公楼 |
| 夜间异常 | 夜间占比>30% | 地下水入渗等 |

**描述示例**：
> 一天内出现多个间隔相近的波峰，呈锯齿状规律涨落，疑似泵站调控

### 第3类 - 曲线平坦/异常

**特征**：
- Kz < 1.2
- 无周期性规律
- 波动范围 < 30%

**描述示例**：
> 曲线平坦，Kz=1.09，无明显波动

---

## 常见误判及纠正

### 误判1：把生活污水高峰当作周期性波峰

**错误原因**：波峰检测到早上、中午、晚上三个高峰，误判为周期性

**正确判断**：生活污水高峰集中在特定时段，无深夜波峰

### 误判2：Kz<1.2 归为第1类

**错误原因**：LLM忽略了Kz规则

**正确判断**：Kz<1.2 绝对不能归为第1类

### 误判3：微小波动当作周期性规律

**错误原因**：曲线有轻微起伏就被判断为周期性

**正确判断**：需要>=4个波峰且有显著深夜波峰
