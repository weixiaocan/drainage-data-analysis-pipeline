# 排污规律分类示例

## 示例1：典型生活污水（第1类）

**点位**：36157_#2-19-1

**特征数据**：
- Kz = 3.19
- 波峰数量 = 7（但无显著深夜波峰）
- 夜间平均 = 2.77 L/s（日均的32%）
- 早上峰值 = 23.65 L/s（日均的2.71倍）
- 晚上峰值 = 21.34 L/s（日均的2.45倍）

**判断过程**：
1. Kz=3.19 >= 1.2 ✓
2. 无显著深夜波峰 → 无周期性规律
3. 夜间最低 ✓、晚上高峰明显 ✓、早上有小高峰 ✓
4. → **第1类**

**描述**：
> 夜间流量最低，早上和中午高峰明显，晚上高峰突出，符合典型生活用水排放规律

## 示例2：典型泵站调控（第2类）

**点位**：35952_#7

**特征数据**：
- Kz = 2.12
- 波峰数量 = 5
- 波峰时间 = 04:36, 06:52, 12:51, 14:51, 23:11
- 有深夜波峰（04:36，流量>日均）

**判断过程**：
1. Kz=2.12 >= 1.2 ✓
2. 有显著深夜波峰（04:36） → 有周期性规律 ✓
3. → **第2类**

**描述**：
> 一天内出现5个波峰，约4小时一个周期，呈锯齿状规律涨落，疑似泵站调控

---

## 示例3：平坦曲线（第3类）

**点位**：36154_#2-16

**特征数据**：
- Kz = 1.13
- 波动范围 = 24%（< 30%）
- 波峰数量 = 1
- 48个半小时数据都在 107-127 L/s 范围内

**判断过程**：
1. Kz=1.13 < 1.2 ✓
2. 波峰数量=1 < 4 → 无周期性规律
3. → **第3类**

**描述**：
> 曲线平坦，Kz=1.13，波动范围24%<30%，无明显波峰波谷

---

## 示例4：夜间异常（第2类）

**点位**：35891_#1

**特征数据**：
- Kz = 3.38
- 夜间占比 = 73.1%（异常高）

**判断过程**：
1. Kz=3.38 >= 1.2 ✓
2. 夜间占比过高，不符合生活规律
3. → **第2类**

**描述**：
> 夜间流量异常高，占比73.1%，全天流量较为稳定，疑似泵站调控或存在外来水入渗

---

## 示例5：工业脉冲排放（第2类）

**点位**：36144_#2-2

**特征数据**：
- Kz = 22.17（极高）
- 大部分时间流量为0
- 仅9-10点出现脉冲高峰

**判断过程**：
1. Kz=22.17 >= 1.2 ✓
2. 间歇性脉冲排放特征
3. → **第2类**

**描述**：
> 流量集中在早上9-10点，其余时间流量为0或极低，呈脉冲式排放，疑似工业排水

---

## 示例6：早午高峰不突出但有（第1类）

**点位**：36148_#2-8

**特征数据**：
- Kz = 2.32
- 夜间平均 = 4.96 L/s
- 早上峰值 = 8.18 L/s（日均的1.18倍）
- 晚上峰值 = 16.15 L/s（日均的2.32倍）

**判断过程**：
1. Kz=2.32 >= 1.2 ✓
2. 无显著深夜波峰 → 无周期性规律
3. 夜间最低 ✓、晚上高峰明显(2.32倍) ✓、早上有小高峰(1.18倍>日均) ✓
4. → **第1类**

**描述**：
> 夜间流量最低，晚上高峰明显（峰值16.2L/s为日均的2.3倍），早上有小高峰，符合典型生活用水排放规律

## 分类统计参考

在19个监测点位的测试中，分类结果：

| 分类 | 数量 | 占比 |
|------|------|------|
| 第1类 | 5-7 | 26%-37% |
| 第2类 | 11-13 | 58%-68% |
| 第3类 | 1 | 5% |

典型分布：
- 第1类（生活污水）：居民区监测点
- 第2类（非典型）：泵站下游、工业区、公建区域
- 第3类（平坦）：管网末端、低流量点位
